# Documentation figures

These two PNGs were supplied externally by the project owner and are integrated without recompression. No installation figure is used; Quick Start remains text and copyable code.

| File | Placement / label |
|---|---|
| `emind_overview.png` | Main README, once after the introduction; E-MIND overview |
| `de_cent_contents.png` | DE_CENT page, once; **DE_CENT scenario overview** |

Both images are 1672 × 941 pixels. The overview uses DE_CENT/SMARD as its architecture example; it does not enumerate the current DE_CENT + ES_MED coverage. The second figure also describes DE_CENT only. Neither figure defines source availability or redistribution clearance for other regions. Research-use labels do not imply bundled controllers or a publicly issued dataset package. Textual documentation remains authoritative for status, native fuel cadence and scientific caveats.
